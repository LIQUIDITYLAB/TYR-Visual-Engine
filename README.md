# TYR Visual Engine

A programmable video generation engine that turns structured scene descriptions into rendered MP4 video.

## V1 Pipeline

Natural-language direction will eventually become:

Prompt → Director → Storyboard → Scene Code → Renderer → MP4

V1 starts with a deterministic storyboard and renderer before introducing AI-generated scene code.
